# Ising Model Monte Carlo Simulation

## Overview

This repository contains my Summer Research Internship project carried out at the Department of Physics, Indian Institute of Technology (BHU), Varanasi.

The project implements the 2D and 3D Ising Models using the Metropolis Monte Carlo algorithm in C++ to study magnetic phase transitions. The repository includes the complete source code, simulation outputs, and reports containing plots with their analysis.

## Contents

### 2D Ising
- `ising2d.cpp` – Source code
- `ising_2d_results.txt` – Simulation output
- `2D_Ising_Model_Plots.pdf` – Plots and analysis

### 3D Ising
- `ising3d.cpp` – Source code
- `3D_ising_model_results.txt` – Simulation output
- `3D_Ising_Model_Plots.pdf` – Plots and analysis

## Implemented Features

- Metropolis Monte Carlo Algorithm
- 2D Ising Model
- 3D Ising Model
- Magnetization
- Time Correlation Function
- Spatial Correlation Function
- Structure Factor
- Cluster Analysis
- Ensemble Averaging
- Standard Deviation and Error Bars
- Magnetic Susceptibility
